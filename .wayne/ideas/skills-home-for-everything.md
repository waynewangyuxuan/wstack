# skills-home-for-everything

Goal: The user can install and manage all of their skills, development or not, from wstack, written and maintained one consistent way.
Why: Skills now live in separate repos with different conventions, starting with lib-skill. One home keeps how they are written, managed and installed the same.
Context: lib-skill ships Markdown skills plus the mylibrary Python runtime, so the move must also decide where that runtime lives; wstack's README limits it to hand-made skills that earn a place.
